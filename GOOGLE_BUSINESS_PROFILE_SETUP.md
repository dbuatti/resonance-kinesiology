## Troubleshooting

| Issue | Fix |
|---|---|
| "Duplicate listing" | Report duplicate in GMB dashboard → "Suggest an edit" → "Remove this place" |
| Verification postcard never arrives | Request new postcard (max 3x), then try phone/email |
| Wrong category | Edit → Primary category: "Kinesiologist" |
| Suspended listing | Usually NAP mismatch or policy violation → Appeal with docs (ABN, lease, utility bill) |
